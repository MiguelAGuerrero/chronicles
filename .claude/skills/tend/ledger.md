# The loop's ledger

What `/tend` remembers between runs (decisions 0128, 0129). `/tend` edits this file; nothing else reads it.

- **Last inbox number used:** T0
- **Last evolution number used:** G0
- **Balance:** not yet read (growth, refinement and other commits on `main` over 14 days; areas by state; the reading)

## Areas

States: `rough`, `settling`, `polished`, `resting` (the skill's section 8). An area not listed has never been swept and counts as rough.

| Area | State | Last swept | `main` after the run | Note |
|---|---|---|---|---|

## Declined

Proposals the owner said no to, one line each with the date and the reason. A sweep never files these again.
