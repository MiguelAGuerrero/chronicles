# 0142. A map that mounts on Walks zooms out once, as the walks list does

Date: 2026-11-11 · Status: accepted · Area: chronicle, map · Extends: 0054, 0141 · From: `/tend` inbox T7

## Context
Since 0141 the section bar's Walks zooms out to every place walked as the sheet's Walks does, but only with the map up. From Memories or Media (Chronicle opens on Memories, RM1, so it is a usual way to the walks list) the press only named the section, and the map that mounted on Walks kept the view it was left with (audit 8), a place walked off screen or not: the same word moved the map two ways again (NN/g H4).

## Decision
The owner's yes to T7, Nov 11: a map that mounts on Walks zooms out once, by 0054's rule: only when a place walked (of the walks shown) is out of the kept view, never closer than it, framed above the half sheet. A read that frames the places itself (the first open, a new walk) needs none. Mounting on Days or Map keeps the view as before.

## Consequences
- The kept view (audit 8) still holds for Days and Map, and on Walks whenever every place walked is already in it.
- SB3's wording waits for the owner's amendment (docs/STATUS.md, "Open before the loop").
- Native unverified: the fit on MapLibre RN, as 0141's.
